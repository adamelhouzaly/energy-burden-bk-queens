# Energy Burden in Brooklyn & Queens

**Which neighborhoods spend the largest share of their income on home energy, and where should bill-assistance outreach focus first?**

This project uses public U.S. Census data to estimate *energy burden* (the percent of household income spent on electricity and gas) for every census tract and neighborhood in Brooklyn and Queens. It flags areas above New York's **6% energy affordability threshold** and turns the results into an interactive dashboard, a written findings summary, and a short PowerPoint deck with recommendations.

## What's inside

| File | What it does |
|---|---|
| `src/fetch_data.py` | Downloads ACS 5-year (2018-2022) income + electricity/gas cost data from the Census API |
| `src/analysis.py` | Computes energy burden, flags high-burden areas, writes `outputs/findings.md` and charts |
| `src/make_slides.py` | Builds `outputs/energy_burden_summary.pptx` (5 slides: scope, findings, charts, recommendations) |
| `app.py` | Streamlit dashboard: borough filter, adjustable threshold, rankings, income-vs-burden chart, map, CSV export |
| `tests/` | pytest tests for the burden math, missing-data handling, and neighborhood naming |

## Run it

```bash
pip install -r requirements.txt
python src/fetch_data.py        # downloads real Census data (~1 min)
python src/analysis.py          # prints findings, saves charts
python src/make_slides.py       # builds the PowerPoint summary
streamlit run app.py            # opens the dashboard
pytest                          # runs the tests
```

If the Census API asks for a key, get a free one at <https://api.census.gov/data/key_signup.html> and run
`CENSUS_API_KEY=your_key python src/fetch_data.py` (Windows PowerShell: `$env:CENSUS_API_KEY="your_key"`).

## Method

- **Data:** ACS tables B19013 (median household income), B25132 (monthly electricity costs), B25133 (monthly gas costs).
- **Average monthly cost** per area = sum of (households in each cost bracket × bracket midpoint) ÷ all households. Households whose utilities are included in rent count as $0 out of pocket.
- **Energy burden** = 12 × (avg electricity + avg gas) ÷ median household income.
- **High burden** = 6% or more, the affordability target used in New York energy policy.
- Neighborhoods are Census PUMAs, which line up with NYC community districts.

## Limitations (read before quoting numbers)

- These are **area-level estimates**, not household measurements. Using median income and bracket midpoints simplifies reality; the top brackets are open-ended.
- Excludes heating oil and other fuels, and renters whose utilities are bundled into rent show $0 energy cost, so true burden for some households is higher.
- ACS estimates have margins of error, especially for small tracts.
- Good for **prioritizing where to look**, not for determining any individual household's eligibility.
